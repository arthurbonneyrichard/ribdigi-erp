# Retail feature matrix

**Date:** 2026-10-13. Status: **ready for market / not certified.**

This matrix compares the retail completion request with the code in this tree. “Verified” means a check that was actually run in this pass. Items marked “Code only” were read in source and were not exercised in a signed-in browser or a full suite.

The 120-case retail checklist and a separate Retail Source Brief file are not in this repository.
